# The REDUX Programming Language

Please note that The REDUX Programming Language project is licensed under the GNU General Public License v3.0 (GPL-3.0).

The official repository for the REDUX programming language. REDUX is a compiled, optionally typed, low/high level, and context sensitive language designed to redefine the term "Modern language".

# How to install
REDUX provides prebuilt binaries directly inside the REDUX Repository alongside the Source Code. The Source Code is provided for users that wish to compile the language themselves. These files are provided under the GNU General Public License v3.0 (GPL-3.0)
